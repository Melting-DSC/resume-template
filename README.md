# Typst用レジュメテンプレート

## 概要

Typstで利用できるレジュメのテンプレートです。

## 使用方法

このリポジトリをローカルにクローンし、`sample.typ`をコピーして内容を書き換えるか、既存のtypファイルにインポート等して使ってください。

## ファイル説明

- `template.typ`: テンプレート本体。利用したい場合はインポートするか、後述の`sample.typ`を編集して利用するようにしてください。基本的には書き換えず、全体の設定を変えたいときだけ書き換えるようにしてください。
- `sample.typ`: テンプレートを利用した文章のサンプル。こちらのサンプルをコピーし、編集して利用するのが手っ取り早く使えると思います。
- `sample.pdf`: `sample.typ`のpdf出力結果。どういう見た目になるか確認できます。
- `sample.png`: `sample.typ`で使用している画像。AI生成画像なので著作権フリー…のはずです。画像の内容には特に意味はありません。
- `ipsj.csl`: 情報処理学会(IPSJ)の引用スタイルを記録したcslファイル。Typst付属の`bibliography`機能を利用したい場合はこちらのスタイルを利用することで、情報処理学会の形式を使いながら引用ができるはずです。`sample.typ`では、現時点では利用していません。
